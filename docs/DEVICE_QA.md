# HARU Android 실제 단말 QA 체크리스트

## 준비

- [ ] Android 실제 단말에 최신 `app-debug.apk`를 설치한다.
- [ ] 기존 데이터 영향이 없도록 앱 데이터 삭제 후 처음부터 시작한다.
- [ ] 배터리 절약 모드와 일반 모드에서 각각 핵심 시나리오를 확인한다.
- [ ] 홈 화면에 HARU Medium 위젯을 추가한다.
- [ ] 테스트 중 시스템 시각을 변경했다면 마지막에 자동 날짜 및 시간을 다시 켠다.

## 기본 표시

- [ ] 온보딩 완료 직후 위젯에 현재 상태와 예산이 표시된다.
- [ ] 근무 중에는 큰 숫자 뒤에 `퇴근까지`가 표시된다.
- [ ] 퇴근 후에는 큰 숫자 뒤에 `퇴근 후 자유`가 표시된다.
- [ ] 휴무 Override를 적용하면 `휴무 · 오늘은 쉬는 날`이 표시된다.
- [ ] 오늘 권장 금액과 이번 달 남은 생활비가 Dashboard와 일치한다.
- [ ] 위젯의 갱신 시각이 현재 Snapshot 생성 시각과 일치한다.

## 이벤트 기반 자동 갱신

- [ ] 출근 직전 설정으로 테스트하고, 앱을 최근 앱 목록에서 제거한 뒤 출근 시각 이후 위젯이 근무 상태로 바뀐다.
- [ ] 퇴근 직전 설정으로 테스트하고, 앱을 열지 않은 상태에서 퇴근 후 상태로 바뀐다.
- [ ] 취침 직전 설정으로 테스트하고, 취침 시각 이후 수면 상태로 바뀐다.
- [ ] 기상 직전 설정으로 테스트하고, 기상 시각 이후 출근 전 상태로 바뀐다.
- [ ] 23:59 이전 Snapshot을 만든 뒤 자정 이후 이전 날짜의 금액과 문구가 그대로 노출되지 않는다.
- [ ] `cycleStartDay` 전후로 오늘 권장 금액과 남은 생활비가 새 주기 기준으로 바뀐다.
- [ ] 갱신은 이벤트 시각 주변에서만 발생하며 매분 위젯 갱신이 발생하지 않는다.

> WorkManager는 배터리 최적화를 따르는 지연 허용 작업이다. 제조사 정책이나 절전 모드에 따라 이벤트 직후 수 분 늦게 실행될 수 있다.

## Override와 자정

- [ ] 야근 종료 시간을 자정 이후로 설정하고 자정 전후에 근무 상태가 유지된다.
- [ ] 야근 종료 시각 이후 퇴근 후 상태로 바뀐다.
- [ ] 늦게 자기를 자정 이후로 설정하면 자정 이후에도 자유시간이 올바르게 표시된다.
- [ ] 일반 DayOverride는 다음 날 같은 시간대에 남아 있지 않는다.
- [ ] 휴무 Override를 취소하면 기본 근무 일정으로 복원된다.

## 지출 및 Quick Action

- [ ] 위젯의 `지출 입력`을 누르면 앱의 오늘 지출 입력/수정 창이 열린다.
- [ ] 금액 입력 후 오늘 권장 금액과 이번 달 남은 생활비가 즉시 갱신된다.
- [ ] 같은 날짜의 지출을 수정하면 누적 추가가 아니라 새 금액으로 교체된다.
- [ ] 위젯의 `일정 변경`을 누르면 일정 변경 메뉴가 열린다.
- [ ] 일정 변경 완료 후 위젯 상태와 다음 갱신 예약이 새 일정 기준으로 바뀐다.

## 알림 권한 거절

- [ ] 앱을 재설치하고 알림 권한 요청에서 `허용 안 함`을 선택한다.
- [ ] 온보딩, Dashboard, Override, 지출 입력이 정상 동작한다.
- [ ] 홈 위젯 추가와 Snapshot 갱신이 정상 동작한다.
- [ ] 앱을 재실행해도 권한 거절 때문에 시작 화면에서 멈추거나 종료되지 않는다.

## Android 16 Live Update / 삼성 Now Bar

- [ ] Android 16(API 36) 이상 단말에서 HARU 알림 권한과 잠금화면 알림을 허용한다.
- [ ] Galaxy에서는 `설정 > 잠금화면 및 AOD > Now Bar > Live notifications`에서 HARU를 켠다.
- [ ] HARU의 `설정 > 잠금화면 실시간 정보`에서 시스템의 promoted notification 설정을 열 수 있는지 확인한다.
- [ ] `설정 > 개발자 진단 > Live Update 진단`에서 Android 버전, 권한, 채널과 현재 HARU 상태가 표시된다.
- [ ] 진단 정보 복사 후 메모 앱에 붙여 넣었을 때 각 항목이 한 줄씩 포함된다.
- [ ] 근무 중에는 `HARU · 근무 중`, 퇴근까지 남은 시간, 진행률이 표시된다.
- [ ] 퇴근 시각을 통과하면 앱을 열지 않아도 `HARU · 내 시간`으로 바뀌고 자유시간 진행률이 0%부터 시작한다.
- [ ] 잠금화면의 시스템 카운트다운이 앱을 열지 않아도 계속 감소한다.
- [ ] 진행률은 매분 polling하지 않고 각 구간의 25%·50%·75%와 상태 전환 시점에 갱신된다.
- [ ] 퇴근 시각 카드의 `퇴근했어`를 누르면 자유시간 상태로 즉시 바뀌고 홈 위젯도 갱신된다.
- [ ] `+30분`, `+1시간`을 누르면 근무 종료가 연장되고 변경된 퇴근 시각에 확인 알림이 다시 온다.
- [ ] 일반 퇴근 알림의 `야근 중이야`를 누르면 앱의 직접 시간 설정을 포함한 compact 선택 화면이 열린다.
- [ ] `잠금화면 돈 정보` 기본값이 `숨김`이고, `표시`를 선택했을 때만 오늘 사용 가능 금액과 이번 달 잔액이 보인다.
- [ ] 취침 시각을 통과하면 Live Update가 종료된다.
- [ ] 출근 전, 휴무, 수면 시간에는 Live Update가 표시되지 않는다.
- [ ] Android 15 이하 또는 promotion 미허용 상태에서는 같은 내용이 일반 진행 알림으로 표시된다.
- [ ] 앱을 최근 앱 목록에서 제거한 상태에서도 예약된 출근·퇴근·취침 전환이 반영된다.
- [ ] 재부팅 후 Flutter가 만든 마지막 전환 계획이 복원되고, 종료 시각이 지난 알림은 다시 표시되지 않는다.
- [ ] 알림 권한을 거절하면 Live Update만 표시되지 않고 Dashboard, 위젯, 일정 및 지출 기능은 정상 동작한다.

> promoted notification 요건을 충족해도 최종 Now Bar 노출 여부는 단말 모델, One UI 버전, 지역 및 삼성 시스템 정책이 결정한다.

## 프로세스 종료와 재부팅

- [ ] 최근 앱 목록에서 HARU를 제거한 뒤 다음 이벤트 시각까지 앱을 열지 않는다.
- [ ] 이벤트 이후 위젯이 새 Snapshot으로 갱신된다.
- [ ] 위젯이 표시된 상태에서 단말을 재부팅한다.
- [ ] 재부팅 직후 마지막 Snapshot 또는 안전한 `갱신 중` 상태가 표시된다.
- [ ] 예약 이벤트 실행 후 최신 Snapshot으로 복원된다.
- [ ] Android 설정에서 앱을 강제 종료한 경우에는 Android 정책상 백그라운드 작업이 중단되며, 앱을 다시 연 뒤 예약이 복원되는지 확인한다.

## 선택적 ADB 확인

```text
adb shell dumpsys jobscheduler | findstr haru
adb shell dumpsys appwidget | findstr HaruWidgetProvider
adb shell dumpsys notification --noredact | findstr /i "haru_live_update promoted"
adb logcat | findstr /i "WorkManager HARU"
```

- [ ] `HaruWidgetProvider`가 설치된 위젯 Provider로 등록되어 있다.
- [ ] `haru.widget.nextEvent`에 해당하는 one-shot 작업이 존재한다.
- [ ] 작업 실행 후 다음 이벤트를 위한 새 one-shot 작업이 등록된다.
